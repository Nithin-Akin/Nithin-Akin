## 🧠 About Me

I'm **Nithin**, an Artifical Engineering intern and student from **Bengaluru, India**, focused on **AI Frameworks, LLM systems, and backend development**.

I like building things where the interesting part isn't just the model — it's everything around it: retrieval, agents, tool use, evaluation, and failure handling.

> **I don't just want the model to answer. I want to understand the system that makes the answer possible.**

## 💭 Engineering Philosophy

**"Don't just use the abstraction. Understand what's underneath it."**

A working demo ≠ a working system. If it can fail, understand how it fails. If it makes a decision, make the decision explainable.
