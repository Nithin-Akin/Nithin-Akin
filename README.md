🚀 Things I’ve Built

🧾 Multi-Agent Invoice Reconciliation

invoice-reconciliation-agent-system

A multi-agent system designed to automate invoice processing and reconciliation.

Instead of one giant prompt doing everything, the system separates the workflow into specialized agents:

                  INVOICE
                     │
                     ▼
        ┌─────────────────────────┐
        │ Document Intelligence   │
        │ OCR + Extraction        │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │ Matching Agent          │
        │ Exact + Fuzzy Matching  │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │ Discrepancy Detection   │
        │ Price / Qty / Supplier  │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │ Resolution Agent        │
        │ Approve / Review / Esc. │
        └─────────────────────────┘

Highlights

* Multi-agent orchestration
* PDF & scanned-document processing
* OCR with preprocessing
* Exact + fuzzy purchase-order matching
* Confidence scoring
* Discrepancy detection
* Transparent agent reasoning
* Execution traces
* Graceful error handling
* Batch processing

The system successfully handles cases such as price traps and missing PO references, including fuzzy matching when the purchase-order reference is unavailable. (GitHub)

Stack: Python OpenCV Tesseract pdfplumber OCR Multi-Agent Systems

🏗️ How I Like Building AI Systems

I care about what happens after the demo works.

Prototype
   ↓
Does it actually work?
   ↓
Can I measure it?
   ↓
What happens when retrieval fails?
   ↓
What happens when the model is wrong?
   ↓
Can I trace the decision?
   ↓
Can I test individual components?
   ↓
Can the system recover?
   ↓
Ship.

For me, AI engineering isn’t just about getting a model to produce an impressive answer.

It’s about building the system around the model.
